# 刃影管理后台

管理后台有两种用法：Cloudflare Worker 上的网页（`/admin`），和终端里的命令 `node tools/econ-admin.mjs`。两边能做的事一样：

- 查玩家的武库、处罚记录、流水和市场记录。
- 给一个号加减墨锭、武器箱、终端机、改名标签，发饰品或者收走饰品。
- 封号、解封。
- 给一个号重设密码，这个号在所有设备上的登录都会退出。开发组的 Dev 账号也只能在这里建号、改密码。
- 给全服或者某一个号发补偿，玩家下次登录或打开武库时自动领到。
- 建礼包兑换码：玩家在游戏的「任务 → 礼包兑换」里输入就领到，每个号只领一次，可以限几个号能领、几天内有效。
- 在线改武库的经济数值：价格、爆率、每天能开几个、手续费、对局掉落、每天认多少本机收入。改错了可以退回。

每一笔修改都要写原因，记进「操作记录」，看得到是谁、什么时候、对谁做了什么。

后台只管武库经济和封号。英雄的伤害、血量这些对战数值写在代码里，段位分和英雄解锁在玩家自己的存档里，后台都不改。游戏没有充值，后台也不接任何付款。

## 第一次设置（只做一次）

管理口令放在 Worker 的 Secret 里，不写进代码，也不放进网页。每个人用自己的口令，流水里会记下是谁做的。口令至少 16 位，短的服务器不认。

Worker 要先更新到带管理后台的版本，在仓库文件夹里按平时的三步部署：

1. 拉取最新的代码：

   ```
   git pull --rebase origin main
   ```

2. 进到 `cloudflare` 文件夹：

   ```
   cd cloudflare
   ```

3. 部署：

   ```
   npx wrangler deploy
   ```

然后设口令：

4. 每个人生成一个口令。这条每运行一次出一个新的，要几个人就运行几次：

   ```
   openssl rand -hex 24
   ```

5. 把它们拼成一行，写成「名字:口令」，几个人用英文逗号隔开，比如 `even:第一个口令,lnt:第二个口令`。名字会显示在操作记录里。

6. 还在 `cloudflare` 文件夹里，运行下面这条，提示 `Enter a secret value` 时粘贴第 5 步那一行，回车：

   ```
   npx wrangler secret put ADMIN_SECRET
   ```

   不想用终端的话，也可以在 Cloudflare 网页上设：Workers & Pages → renying → Settings → Variables and Secrets → Add，类型选 Secret，名字填 `ADMIN_SECRET`，值填第 5 步那一行，保存并部署。

7. 口令只私下发给本人。不要发在群里，不要截图，也不要写进代码或者文档。

8. 给 Dev 设一次密码：云端已经有 Dev 就重设，还没有就建一个，做法见下面「Dev 账号」一节。

### 换口令、收回口令

再运行一次第 6 步，填新的一行就行。旧口令马上失效，已经登录的网页会提示重新输入。有人不再管理了，就把那个人的那一段从这一行里删掉。

## 网页上的几页

### 总览

注册账号数（和 24 小时内新注册的）、有武库存档的账号、全服墨锭、市场在卖的单数、24 小时内成交的单数和成交额、封禁中的账号、经济数值现在用的是第几版，下面是最近的 8 条管理员操作。

### 玩家

按昵称开头或者账号编号（`u_` 开头）找人，不填就列出最近动过武库的号。点进去能看到墨锭、每种武器箱、终端机、改名标签、库存里的饰品、处罚记录、最近的流水和市场记录。

- **调整**：墨锭、每种武器箱、终端机、改名标签填加减多少（扣就填负数），还可以发饰品（普通版或者斩数版）、勾选要收走的饰品。一次最多加减 1,000,000 墨锭、1,000 个箱子 / 终端机 / 标签，最多发 50 件、收 200 件。扣不到负数；挂在市场上的饰品要等玩家撤下或者卖掉才能收。确定之前会把要改的再列一遍，并且要写原因。玩家正好在线也没关系，不会互相覆盖，玩家下次打开武库就能看到（开着武库的话一分钟内）。
- **封号**：封 1 到 3650 天，或者永久。被封期间不能同步存档，也不能交易。
- **解封**：清空这个号的处罚记录，玩家刷新网页后生效。
- **重设密码**：填一个新密码（12 到 128 位），或者点「随机生成」。重设以后，这个号在所有设备上的登录都会退出，因为输错太多被锁住的也会解开。新密码只在确认框里显示这一次，记下来私下发给本人。

### 补偿

发给所有人或者一个号。内容可以有墨锭（最多 1,000,000）、每种武器箱、终端机、改名标签（每样最多 100）。要写一句给玩家看的说明（2 到 60 个字，比如「服务器维护补偿」），有效 1 到 90 天，默认 14 天。

- 发给所有人时，默认只有现在已经注册的号能领。勾上「之后新注册的账号也能领」，有效期内新注册的号也能领。
- 玩家下次登录或打开武库时自动领到，游戏里会弹出「开发组补偿：说明（内容）」。每个号只领一次。
- 列表里能看到每一份有多少人领了。
- **停发**：还没领的就领不到了，已经领到的不收回。

### 兑换码

建一个码发给玩家（比如发在群里、活动帖里），玩家在游戏的「任务 → 礼包兑换」里输入就领到。内容和补偿一样：墨锭（最多 1,000,000）、每种武器箱、终端机、改名标签（每样最多 100），还要写一句给玩家看的说明（2 到 60 个字，比如「新春礼包」）。

- 码可以自己起（4 到 20 位英文字母和数字，不分大小写），不填就随机生成 10 位（不用 0、O、1、I、L，免得玩家看错）。和游戏里原来写死的几个码同名的建不了。
- 「最多几个号能领」默认 100，领满就停；有效 1 到 90 天，默认 14 天。
- 每个号只领一次，要登录云端账号才能领。玩家看到的是「兑换成功：说明（内容）」，东西直接进存档和墨锭。
- 码公开发出去，看到的人都能领。只想给少数人，就用随机生成的码，人数也设小一点。
- 同一个号一小时里输错 10 次、同一个 IP 输错 30 次，就先锁一小时，防止有人乱猜。
- 列表里能看到每个码领了几份、什么时候截止。
- **停用**：还没领的就领不到了，已经领到的不收回。
- 码只存在服务器上，不在代码里。这次更新部署好以后，建码、停用都不用改代码，也不用重新部署。

### 经济数值

每一项都有默认值和上下限，不合理的数会被拒绝：同一种箱子的几档爆率加起来要正好是 1，终端机报价的最低倍数不能高过最高倍数。改完存成新的一版，最多半分钟全服生效，武库里显示的价格和次数也跟着变。

这些数直接影响全服经济。比如箱子降价太多、或者高档爆率调得太高，开箱就可能稳赚，大家会拼命刷。改之前想好，改完看一眼总览，不对就退回。

- **退回**：在历史里点某一版，就回到那一版。退回也存成新的一版，以前的记录不会丢。
- **全部回到默认值**：一键回到代码里写的默认数值。

## Dev 账号

Dev 是开发组的市场账号：墨锭、武器箱和饰品不受库存限制，用来往玩家市场上放货。别人注册不了这个昵称，它的密码也只能在管理后台设。

- 云端还没有 Dev：在网页的「玩家」页搜 `Dev`，下面会出现「建 Dev 账号」，填密码或者点「随机生成」，再点「建号」。命令行用下面的第 13 步。
- 已经有 Dev：在网页上打开 Dev，用「重设密码」；命令行用下面的第 12 步，把 `小明` 换成 `Dev`。
- 谁拿到 Dev 的密码，谁就能往市场上放不限量的货。所以 Dev 的密码要和管理口令一样保管，只私下发给要用的人。
- 时不时看一眼 Dev 的流水和市场记录，有不认识的挂单或者交易，就马上重设密码。

## 命令行

网页能做的，终端里也能做（要装 Node.js 18 或更新的版本）。先在仓库文件夹里把口令放进这个终端窗口：

1. 进到仓库文件夹：

   ```
   cd ~/Desktop/RenYing
   ```

2. 运行后粘贴自己的口令（冒号后面那一段），回车。屏幕上不显示，口令也不会记进命令历史：

   ```
   read -s ADMIN_SECRET
   ```

3. 让后面的命令都用得上它：

   ```
   export ADMIN_SECRET
   ```

4. 看看口令对不对、流水里记成谁：

   ```
   node tools/econ-admin.mjs whoami
   ```

关掉这个终端窗口，口令就没了，下次再做一遍第 2、3 步。下面是常用的命令，`<号>` 写昵称或者账号编号，修改都要用 `--why` 写原因。

5. 总览：

   ```
   node tools/econ-admin.mjs stats
   ```

6. 按昵称开头找人：

   ```
   node tools/econ-admin.mjs find 小明
   ```

7. 看一个号的武库、处罚、市场记录和最近 100 条流水（库存里每件饰品的编号也在这里）：

   ```
   node tools/econ-admin.mjs log 小明
   ```

8. 加 500 墨锭、2 个初刃武器箱、1 台终端机（`c1` 到 `c8` 是八种武器箱，`c8` 是星座武器箱，扣就写负数，比如 `ink=-200`）：

   ```
   node tools/econ-admin.mjs adjust 小明 ink=+500 c1=+2 term=+1 --why "开箱没到账"
   ```

9. 发一件饰品、一件斩数版（`@0` 是斩数从 0 开始），收走库存里第 12 号：

   ```
   node tools/econ-admin.mjs adjust 小明 give=qf_p1 give=gc_wolf@0 take=12 --why "活动奖励"
   ```

10. 封 3 天（永久就把 `3` 换成 `perm`）：

    ```
    node tools/econ-admin.mjs ban 小明 3 --why "刷墨锭"
    ```

11. 解封：

    ```
    node tools/econ-admin.mjs unban 小明 --why "误封"
    ```

12. 重设密码。会随机生成一个 20 位的新密码，只显示这一次；这个号在所有设备上的登录都会退出：

    ```
    node tools/econ-admin.mjs password 小明 --why "玩家忘了密码"
    ```

13. 云端还没有 Dev 时建 Dev 账号（已经有了，就和第 12 步一样是重设密码）：

    ```
    node tools/econ-admin.mjs password Dev --create --why "建开发组的市场账号"
    ```

14. 给所有人发补偿，14 天内能领（加 `--new` 之后新注册的号也能领；把 `all` 换成昵称就只发给一个号）：

    ```
    node tools/econ-admin.mjs gift all ink=500 c1=1 --note "服务器维护补偿" --days 14
    ```

15. 看发过的补偿和补偿编号：

    ```
    node tools/econ-admin.mjs gifts
    ```

16. 停发一份补偿（编号在第 15 步里看）：

    ```
    node tools/econ-admin.mjs gift-off 补偿编号 --why "发错了"
    ```

17. 建兑换码 SPRING2026：500 墨锭和 1 个初刃武器箱，最多 200 个号能领，30 天内有效（不写 `SPRING2026` 就随机生成 10 位）：

    ```
    node tools/econ-admin.mjs code SPRING2026 ink=500 c1=1 --note "新春礼包" --uses 200 --days 30
    ```

18. 看建过的兑换码、各领了几份：

    ```
    node tools/econ-admin.mjs codes
    ```

19. 停用一个兑换码：

    ```
    node tools/econ-admin.mjs code-off SPRING2026 --why "活动结束了"
    ```

20. 看经济数值：现在用的、默认值、范围、最近改过的版本：

    ```
    node tools/econ-admin.mjs cfg
    ```

21. 改经济数值（键看上面的表；值写 `default` 就回到默认）：

    ```
    node tools/econ-admin.mjs cfg-set price.c1=300 fee=0.1 --why "初刃涨价"
    ```

22. 退回到第 3 版（写 `0` 就是全部回到默认值）：

    ```
    node tools/econ-admin.mjs cfg-undo 3 --why "涨价效果不好"
    ```

23. 管理员做过的事：

    ```
    node tools/econ-admin.mjs audit
    ```

连本机测试服务器时，先设 `RENYING_CLOUD_API`（比如 `http://127.0.0.1:8787`），不设就连正式服务器。

## 安全

- 口令只在 Worker 的 Secret 里，代码、网页和这份说明里都没有。每人一个口令，操作记录写着是谁；怀疑泄露就马上换。
- 同一个 IP 一小时内试错 20 次就锁一小时；少于 16 位的口令一律不认。
- 管理网页只运行它自己那一段脚本（浏览器按 sha256 放行），不能被别的网站嵌进去，也不会被缓存。昵称、原因这些字都转义以后才显示。
- 兑换码只存在服务器上；每个号只领一次，好几个号同时抢也不会超过设的份数；输错太多次会先锁住，乱猜猜不出来。
- dev、admin、官方、管理员这类昵称别人注册不了。Dev 是唯一库存不受限的账号，它的密码和别的号一样只存在服务器上，只能在后台建号、重设。
- 所有修改都和玩家自己的操作走同一套带版本号的写入，玩家同时在开箱也不会丢账。
