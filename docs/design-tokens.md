# 设计 token

所有 token 都写在 `src/style.css` 开头的 `:root` 里。以前它们分散在样式表的五个地方（基础、对战大厅、顶栏、水墨层、墨金层），现在收到了一处，值都没改。新写的样式请直接用下面的变量，不要再写一遍颜色或数字。

`:root` 之外只保留两处覆盖：深色模式下的 `--bg` / `--ink`，和矮屏（高度 ≤ 520px）把 `--nav-h` 改成 46px。

## 颜色

| token | 值 | 用在哪 |
| :--- | :--- | :--- |
| `--bg` | `#0a0b1c` | 页面底色 |
| `--ink` | `#efe8d8` | 正文 |
| `--dim` | `rgba(239,232,216,.62)` | 次要文字、说明 |
| `--faint` | `rgba(239,232,216,.16)` | 分隔线、很淡的底 |
| `--gold` | `#e9c46a` | 强调、标题小字、选中 |
| `--p1` / `--p2` | `#46d3ea` / `#ff4a5f` | 1P 青、2P 红（也是「友方 / 敌方」） |
| `--seal` / `--seal-red` | `#b8392e` | 朱砂印 |
| `--line` | `rgba(236,232,225,.12)` | 面板发丝边 |
| `--panel` / `--panel2` | `rgba(13,21,30,.84)` / `rgba(22,32,44,.9)` | 面板底、面板里再一层 |
| `--v-red` `--v-navy` `--v-navy2` `--v-white` | | 对战大厅（竞技风） |
| `--ink-black` `--rice` `--ink-violet` | | 水墨层：墨牌、宣纸、紫墨 |
| `--x-red` `--x-jade` `--x-violet` `--x-gold`（各带 `-hi` / `-lo`） | | 墨金层按钮三档色：亮、正、暗 |
| `--x-paper` `--x-line` `--x-line-hi` | | 墨金层纸色、发丝边、金色发丝边 |
| `--scrim` | `rgba(5,8,12,.72)` | 弹窗后面的遮罩 |

## 字体

| token | 用在哪 |
| :--- | :--- |
| `--title` | 毛笔标题（马善政、楷体） |
| `--body` | 正文（思源宋体、宋体） |
| `--nav-serif` | 顶栏英文衬线 |
| `--v-cond` | 对战大厅的窄体数字和英文 |

## 字号

最常用的几档（现有样式里出现次数最多的）：`--fs-xs` 12px、`--fs-sm` 13px、`--fs-md` 14px、`--fs-lg` 16px、`--fs-xl` 20px、`--fs-2xl` 26px、`--fs-title` 30px。界面文字不小于 12px（`tools/ui-audit.mjs` 会查）。

## 间距

4 的倍数：`--sp-1` 4px、`--sp-2` 8px、`--sp-3` 12px、`--sp-4` 16px、`--sp-5` 20px、`--sp-6` 24px。

## 圆角、切角

| token | 值 | 用在哪 |
| :--- | :--- | :--- |
| `--r-sm` | 4px | 小标签、小按钮 |
| `--r-md` | 8px | 卡片 |
| `--r-lg` | 12px | 大面板 |
| `--r-pill` | 999px | 胶囊 |
| `--x-cut` | 10px | 墨金层按钮、面板的对角切角 |

## 阴影

`--sh-pop`：弹窗、浮层；`--sh-inset`：主按钮的内高光和内阴影。

## 动效

`--dur-fast` .15s（悬停、按下）、`--dur` .2s（展开、切换）、`--dur-slow` .42s（入场）、`--ease-out` 回弹缓出。尊重 `prefers-reduced-motion`。

## 层级

`--z-toast` 40、`--z-modal` 60。

## 底图

`--brush-ink` / `--brush-jade` / `--brush-violet`：水墨层按钮的笔触底图；`--x-grain`：墨金层纸纹。
