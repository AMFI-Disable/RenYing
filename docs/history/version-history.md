# 刃影版本迭代史

这份文档按时间顺序记录刃影从第一个能玩的版本 v0.1 到现在的每一次迭代：每个版本加了什么、改了什么、怎么部署上线。墨锭、问剑阁、武库、市场这些经济和运营上的变化，也放在它们出现的那个版本里一起写。

资料来源：GitHub 仓库的提交记录（2026-10-13 起）、`changelog.md`、`docs/` 和 wiki、仓库建立之前的开发对话（2026-09-23 到 10-03），以及 v3.9 到 v5.4.1 的存档文件。日期都是北京时间。

## 版本号是怎么来的

刃影前后用过三套版本号，读下面的内容时要分清：

| 时期 | 版本号 | 说明 |
| :--- | :--- | :--- |
| 2026-09-23 到 10-13 | v0.1 到 v4.5 | 仓库建立之前，游戏是一个 HTML 文件，每次更新改一次 `VERSION`。联机双方的版本必须一样 |
| 2026-10-13 到 10-26 | 一直是 4.5 | 代码搬进 GitHub 仓库后，游戏里的版本号停在 4.5，但这段时间的改动最多。同期有一条单独的平衡测试线 v5.0 到 v5.4.1 |
| 2026-10-27 起 | 更新日志版本 1.0.0 到 1.0.7；当前客户端 1.0.11 | 正式发布时把版本号重新从 1.0.0 开始算。4.5 时期的改动全部归在 changelog 的 `[4.5]` 一节；最早写着 1.0.0 的首发说明改名为 `[Inaugural]`。1.0.11 是当前开发客户端版本，尚未单独列为更新日志版本 |

## 部署方式的变化

刃影换过很多次"放在哪里、别人怎么打开"。每一次换，都是因为上一种方式碰到了具体的问题。

| 时间 | 方式 | 为什么换 |
| :--- | :--- | :--- |
| 09-23 | 单个 HTML 文件，发给朋友双击打开 | 最简单，但只能本地玩 |
| 09-23 | 局域网联机：先用复制连接码的点对点方式，再改成房主运行 `server.py`、对方输入 IP | 网页不能接收别人的连接，必须有一个转发程序 |
| 09-24（v1.4） | 一台 iMac 运行 `server.py`，用 Cloudflare 免费临时隧道给出一个公开网址；管理脚本 `renying.sh` 负责安装、开服、更新和退回 | 不在同一个 Wi-Fi 也能联机，而且不用花钱 |
| 09-25（v2.0） | 买下域名 renying.site（首年 11 元人民币），把 DNS 交给 Cloudflare，改用固定隧道 | 临时隧道每次重启网址都会变 |
| 09-27（v3.4 之后） | 租一台香港的轻量云服务器，服务器上用 Caddy 自动申请 HTTPS 证书，Cloudflare 只做 DNS | 走 Cloudflare 免费隧道时被绕到美国西岸节点，到服务器要 700 多毫秒。换到香港后降到 120 毫秒左右。大陆机房要备案，所以选香港 |
| 09-28 | 另外做离线版（一个 5.3 MB 的 HTML 文件，音乐打包在里面）和 B 站小游戏平台版（带林中试炼全服排行榜） | 想让更多人玩，又不想服务器被挤爆。10-03 决定不做 B 站版 |
| 10-05 到 10-13 | 更新方式固定为 `scp` 上传新网页，再在服务器上运行 `sudo renying-update` | 网页更新不用重启，玩家开着旧页面会自动刷新 |
| 10-13 | 代码搬进 GitHub 仓库 `AMFI-Disable/RenYing`，Even 成为维护者 | 有版本记录，能多人协作，也能用 GitHub Actions 自动测试 |
| 10-13 到 10-15 | 改成 100% 无服务器：网页放在 GitHub Pages，联机改成 PeerJS 牵线的 WebRTC 点对点，账号同步到 Firestore，同时支持在浏览器里导出、导入账号 | 香港服务器 10-27 到期，静态网页加点对点不需要一直开着的服务器 |
| 10-16 到 10-21 | 先后试了 `renying.js.org` 和 `renying.is-cool.dev` 两个自定义域名，10-21 改回 GitHub Pages 默认地址 `amfi-disable.github.io/RenYing` | 默认地址最稳定，不依赖第三方域名服务 |
| 10-24 | 接入 Cloudflare Worker 和 D1 数据库，武库、墨锭账本、账号都由 Worker 结算；Firestore 后端随后整个移除 | 经济系统必须由服务器说了算，客户端改不了 |
| 10-27 | 开放世界用上 Worker 的 Durable Object，一条分线一个实例 | 很多人同时在一张地图里，需要服务器模拟妖物 |
| 10-28 | `wrangler.toml` 补齐配置（日志、迁移目录、预发布环境），新增部署前检查 `predeploy-check.mjs` 和部署手册 `docs/ops/deploy-runbook.md` | Worker 改动越来越多，部署前要有固定的检查步骤 |
| 11-02 | 表结构改成编号迁移文件，Worker 第一次收到请求时自己执行迁移 | 线上数据库不用手动改表，也不会重复执行 |
| 现在 | 网页推到 `main` 就由 GitHub Pages 自动发布；Worker 和 D1 由 Even 每天部署一次 | |

## 起点：从纸鹤到刃影（09-23）

刃影不是第一个想法。09-23 那天先后做了三个游戏：

1. **纸鹤夜行**：按住空格让纸鹤上升，收集萤火、躲乌鸦，飞过四个地区。画面质感很好，但玩法太薄，玩两分钟就知道全部内容。
2. **星宿**：一个卡牌计分游戏，把星星摆在星盘上连成星线得分，有符咒和 Boss 夜。初代做完后觉得"好无聊"，直接放弃。
3. **刃影**：1v1 横版打斗，要求"很爽很丝滑"。这一个留了下来。

后面所有的版本都是在刃影上一点点长出来的。代码最开头一直留着一段"刃影 v0.1 —— 扩展指南"的注释，就是这个版本留下的。

## v0.x：先把打斗做爽（09-23 到 09-24）

### v0.1（09-23）

- 两位侠客：青锋和绯影。逻辑每秒 120 次，配合 120Hz 屏幕。
- 打击感：每次命中顿帧几十毫秒，重击停得更久；姿势之间用弹簧插值过渡；0.16 秒输入缓冲；剑光拖尾、火花、墨点、震屏、镜头推拉，KO 时慢动作加一个"斩"字印章；围巾是物理模拟的。
- 招式：轻斩连段、重斩挑空、空中下劈，大招"残月"要靠攒气才能放。

### 同一天的连续修改

这一天之内按试玩感受改了十几轮，很多机制是加了又删：

- 攻击改到鼠标左键：点按是攻击，按住蓄力、松开放蓄力斩，蓄满时可以破防。
- 加了一个跟随出刀的"替身"，玩了几次觉得不对，删掉。
- 右键闪避可以连按、几乎一直无敌，于是加了冷却；后来干脆删掉普通闪避，改成"挣脱"：被连击或被挑飞时按右键，原地留下一个稻草假人，自己往后瞬移一小步。这就是"反制"思路的开始：每个强力招式都要有应对的办法。
- 被挑飞后的滞空时间从约 0.7 秒加到 1.2 秒，给空中连段留时间，挣脱也就有了用武之地。
- 轻击改成五段（下劈、上撩、低扫、跃劈、突刺）。
- 刀剑音效重做成多层：破风、刃口脆响、切开的"嘶"、刀身轻颤、格挡时的金属长余音。
- 联机从复制连接码的点对点方式，改成房主运行 `server.py`、对方直接输入 IP 连入。双人同屏模式删除。

## v1.x：角色、联机和第一台服务器（09-24）

### 八位侠客和禁选

- 侠客增加到八位：青锋、绯影、铁山、凌霜、流云、雷鸣、墨羽、月华，每人有不同的属性、被动、Q 技能和大招，武器和头饰造型也不同。
- 克制关系做成真实的机制，而不只是说明文字：刀能砍散飞行道具；雷鸣和铁山的部分招式带霸体，但会被挑空和不可格挡的招式打断；月华的月镜能格开近身攻击，但对飞行道具无效；震地、墨阵、墨龙、天雷都有预兆，能跳开或走开。
- 加入禁选（Ban/Pick）：你禁、对手禁、你选、对手选，每步限时 25 秒。
- 平衡第一次用电脑互打来调：每个组合双方各打 6 场，迭代 5 轮，胜率从 2% 到 80% 收敛到 44% 到 62%。
- 镜头根据双方距离自动拉远，两个人永远在画面里。
- 每场对战开场前出现"Created by Luffy × Opus 5.5"的署名横幅。

### v1.4：iMac 服务器和房间码

- 服务器套件 `renying-server`：`renying.html`、`server.py`、管理脚本 `renying.sh` 和使用说明。
- 联机从输入 IP 改成 4 位房间码，一台服务器可以同时开很多房间。
- 联机数据压缩到原来的五分之一左右，每场对战约 0.3 Mbps。
- 用 Cloudflare 隧道对外，外面的人碰不到这台机器上的其他东西，也看不到它的 IP。
- 更新只需要 `bash renying.sh update 新文件`，旧版本自动备份，`rollback` 一键退回。

### v1.5：快速匹配

- 两个人同时点"快速匹配"，服务器自动配对开房。只匹配游戏版本相同的人。
- 菜单显示正在对战的局数和正在匹配的人数。

### v1.6：账号和排行榜

- 注册只要昵称和密码，密码在服务器上加盐哈希保存，连续输错会被锁。
- 排行榜按胜场排名。只有双方都登录的联机对战才计入，胜负由双方各自上报、一致才算，中途退出算输。
- 服务器管理员多了重设密码和备份数据的命令。

### v1.7：断线重连和延迟显示

- 断线后房间保留 60 秒，重新打开网址自动回到对战，血量、气槽、回合数都和离开前一样。
- 对手是游客时也记"非正式战绩"。
- 选人时可以打字聊天、发 9 个水墨风表情。
- 左下角显示帧率和延迟。
- 降延迟：自己的角色本地优先、命中效果提前播放、对手位置平滑修正、同步频率提到每秒 60 次、同一个 Wi-Fi 可以直连 iMac。

## v2.x：画面、成长与公平（09-25 到 09-26）

### v2.0（09-25）：一次大改版

这一版来自一份 13 条的建议清单，做了下面这些：

- **第九位侠客燕翎**：会飞的侠客，限时飞行。
- **腾空闪**取代原来的挣脱：任何状态下都能用（被大招锁住时除外），解除受制状态并向上闪起，落地或自己出手之前无敌，冷却 9 秒。它不决定胜负，只给被压制的人一个脱困的机会。
- **右键招式二**：九位侠客各一个，比如青锋的剑气、绯影的飞镖、铁山的铁壁冲。之后全部改成"短暂击飞、可以继续连"，蓄力斩改成"直接打倒、不能继续连"。
- **画面**：月亮、灯笼、萤火虫、刀光的泛光；大招电影镜头（先慢放再加速、推近、黑边、对比度提高）；蓄力时镜头推近；暗角和背景景深虚化；震动加大。画质"自动"会限制 5K 屏的渲染分辨率，帧率明显提高。
- **选人界面**：双击确认、更大的立绘卡面、悬停时弹出小窗演示出招。
- **新主界面**：安静的月夜竹林，不再有电脑对打的背景。左边是习武亭（稻草人、箭靶），右边是擂台（战旗、兵器架），鼠标移到按钮上镜头会平移过去。操作说明单独放一页。
- **角色图鉴**：立绘、所有数值、每个招式的伤害和冷却、演示动画。
- **设置**：泛光、帧率上限、画质、背景虚化、震动、暗角、音乐和音效音量。
- **程序生成的原创音乐**：古琴拨弦五声音阶的主界面曲，选人和对战各有一段，残血或最后 10 秒会变急。
- **社区聊天**：游客只能看，登录后才能发言，管理员可以删帖、禁言。
- **联机**：同步数据体积减半，浏览器切到后台时游戏继续运行。
- **木人桩**：不会还手、不会被打死，有站着挨打、一直防御、会腾空闪、固定不动四种模式，右上角显示连击和每秒伤害。
- **固定域名**：管理脚本加了 `domain` 命令，renying.site 审核通过后一条命令切换。
- 同一天还按逐条的数值清单改了全部九位侠客，比如绯影五段普攻合计 33、铁山山崩直击 28、雷鸣普攻改成十下合计 30、墨羽普攻会抛出墨团。

同时做了第一份"开发进度"演示文稿，记录从纸鹤到刃影的过程。

### v2.1（09-26）：排位、墨锭和问剑阁

这一版第一次有了游戏经济。

- **排位赛**：六个自创段位，砺锋、出鞘、破竹、惊鸿、踏月、刃影（1600 分以上）。新号先打 5 场定级赛，分数涨跌是平时的两倍。匹配优先找分数接近的人。
- **货币墨锭**：新号送 500。来源是每天 3 个每日挑战、每周 3 个每周任务、每天第一胜额外 150、各种对局奖励。按"每天正常玩一会儿"测算，一天收入约 550 到 650。
- **问剑阁抽奖**：角色祈愿 60 墨锭一次、十连 540，直接出角色的概率 12%，其余是碎片，碎片可以合成；连续 20 抽没出角色，下一抽必出一个没有的。皮肤祈愿 30 一次、十连 270，连续 15 抽必出皮肤。价格是按"一天大约 10 抽"倒推定的。
- 讨论时 Claude 先提过不建议锁角色抽卡：会和禁选冲突，稀有度也容易变成强度差。最后按 Luffy 的设计做，但加了三条保护：概率全部公开、有保底、每周 3 个限免角色，木人桩里所有角色都能试用。
- 一开始只有青锋，注册后的新手福利可以自选一个任意角色。
- **新手教学**：10 步，每一步都检测你是不是真的做到了，登录后完成给 300 墨锭。
- 用 2 万个模拟账号验证保底：角色最晚第 21 抽出，皮肤最晚第 16 抽出。按每天 10 抽算，集齐全部角色大约要两到三周。

### v2.2 到 v2.5（09-26）：手感细节

- **v2.2**：点右键是腾空闪，按住左键再点右键是远程招式。侠客分成普通、稀有、传说三档：稀有和传说的特效更华丽，并各有一个进阶技巧（比如墨羽可以引爆墨阵、月华格挡成功后月轮冷却清零），但强度不拉开，三档平均胜率是 50%、52%、52%。皮肤祈愿只出已拥有角色的皮肤，碎片一次 1 到 3 个。
- **v2.3**：朝向改成看最后按的是 A 还是 D，不再跟鼠标；取消 F 键重斩，空中连点两下左键就是下砸。
- **v2.4**：位移技能朝角色面对的方向放，不再自动冲向对手。
- **v2.5**：雷鸣的雷闪命中后让对手僵直 0.5 秒。

### v2.6（09-26）：回滚联机

之前的联机是"房主说了算"，房主很流畅，另一方要等房主算完再传回来，所以总是一个人卡、一个人不卡。v2.6 改成格斗游戏常用的回滚网络代码：

- 两边都在自己的电脑上计算整场对战，只交换按键。对方的按键没到时先预测，猜错了瞬间倒回重算。
- 游戏里所有影响结果的随机数都改成双方同步的种子随机数，画面特效的随机数单独分开。
- 测试：随机乱按 5000 帧，40ms 和 100ms 延迟下两边状态 0 次不一致；断线重连后血量和帧数完全一致；每半秒自动比对一次状态。
- **新回合规则**：一回合 25 秒。时间到时，一方过半、一方不过半，不过半的败北；否则加时 15 秒，音乐变急，结束时血量比例低的败北。下一回合继承血量再回一些。

这一版本来打成 v3.0，后来改名为 v2.6。

## v3.x：更深的世界（09-26 到 09-28）

### v3.0（09-26）

- **第四版（下午）**：武器箱（240 到 280，神兵 1000）和货郎（500）改成在固定价格商店买，不限量、不能转卖、系统不回收。**市场只在玩家之间交易**：卖家自己定价 1 到 999,999 墨锭，买家买指定的一单，成交扣 15% 手续费，卖家下次打开武库时到账。挂单存在 Worker 的新表里，"买"和"撤单"同时发生时按原子操作结算。货郎报价改成基准价的 1.2 到 1.5 倍。经济测试改写成 286 项检查。

**经济规则里"没有稳赚的路"是怎么保证的**：价格只在基准价上下 10% 浮动；市场在售比基准价贵 2% 到 12%；直接卖出按 88% 收；自己挂单最高标到 95%；每笔成交扣 15%；货郎报价不低于市场价；每个武器箱的期望价值低于售价。在这些价差下，任何一天买进、以后任何一天卖出，从市场买材料去熔铸，或者转卖货郎的东西，都一定亏墨锭。`econ-test.mjs` 按规则检查最坏情况，并模拟一整年的挂单和熔铸。15% 的手续费也是墨锭流出经济的主要出口，免得墨锭越攒越多。

- **10-27**：从本机账号升级到云账号时，本机墨锭会随注册一起上传，最多带过去 5000（之前会丢，比如 2 万变成 1600）；作废写在源代码里的公开兑换码。
- **10-28**：服务器功能开关；会话令牌哈希存储；密码改用 PBKDF2；接口只允许游戏网页调用；短期令牌加轮换刷新令牌；已登录设备列表和登录记录；注册加人机验证；管理员账号和四种角色（只能看、经济、封禁和账号、全部），每个接口都在服务器上检查权限；账号软删除，可以完整恢复；数据库编号迁移；部署手册。
- **10-30**：**领奖改由服务器记录**：每日、每周、活动任务，活动补偿，教程奖励，关卡星和列传奖励，原来是网页发的、领没领过存在浏览器里，退出登录、清缓存或换设备就能再领一次，重走列传还能反复领节点奖励。现在领奖记录放在服务器上的武库存档里，五种武库动作在服务器上发墨锭，每份只给一次；任务进度只算服务器认可的对局。老账号用服务器上已有的进度做底，不会多领也不会少领。
- **11-02**：
  - Dev 变成普通账号：不再登录就拿到全部侠客、全部皮肤和 100 万墨锭，也不再免除反作弊，开发者兑换码移除。
  - 源代码里的五个公开兑换码全部作废，星座码发出去的物品收回，已经卖给别人的不追回；四个墨锭码发出的墨锭已经混进余额，不追回。
  - 两台设备的进度改成"加起来"而不是"后传的覆盖先传的"：胜负和碎片也像墨锭一样按条记账，每条只算一次。
  - 同一个浏览器的多个标签页保持在同一个账号上；在线人数显示修正；离线进度在加载时上传。

- **修改**：游戏脚本、工具目录、样式表按功能拆分；磁仙、离影加强；PR 检查改成按改动文件并行运行，完整回归改成定时或手动触发。

- **11-03 还有两件事**：武库档位的英文名全部改成游戏自己的叫法（Iron、Jade、Spirit、Crimson 等）；新增 `agents.md`，写明给协作者和 AI 助手的规则。

- **价格涨跌**：饰品价格图显示相对昨天最后一笔成交的涨跌百分比和墨锭数，跌是绿色虚线，涨是红色虚线。
- 管理后台可以按整套或全部系列批量发放皮肤，并统一设置斩数。
- 天魔讨伐的卷轴抽选增加到 10 次、每次 3 选 1，十六位侠客都有专属的天恩卷轴。
- 凌雀的雀芒标记从 15 秒缩短到 5 秒，引爆伤害从 38 降到 30。

- **回放与训练**：新增赛后回放分析、关键时刻标记、逐帧检查，以及连招、压制、招架和脱身专项训练。
