# Screenshots

In-game screenshots of RenYing at 1920×1080, taken in a browser from build 34e1a81 (v1.0.12). `en/` uses the English interface and `zh/` uses the Chinese interface.

- Fight shots come from the built-in AI exhibition mode (AI vs AI on the hardest level), the 16v16 and four-team modes, and Training mode. The frame-rate counter in the bottom-left corner was hidden; nothing else was edited.
- Armory shots were taken on a local test server with a test account and test Ink. They show no real player data.
- The loading screen is the start-up screen held on screen so it can be captured.

## Known Interface Gaps Seen While Capturing

These are not fixed yet.

- In English mode the round start banner ("第一回合"), the "Practice" and "Online Battle" card subtitles, the "Updates" card, the armory type filter ("全部类型"), the welcome-gift banner and several Training panel labels are still in Chinese.
- The home screen tagline says 16 heroes while the draft screen lists 36.
