# Screenshots

In-game screenshots of RenYing at 1920×1080, taken in a browser from build 38bf5e8 (v1.0.7). `en/` uses the English interface and `zh/` uses the Chinese interface.

- Fight shots come from the built-in AI exhibition mode (AI vs AI on the hardest level). The frame-rate counter in the bottom-left corner was hidden; nothing else was edited.
- Armory shots were taken on a local test server with a test account and test Ink. They show no real player data.

## Known Interface Gaps Seen While Capturing

These are not fixed yet. The English set avoids them where it can.

- Round start banners and the 2v2 start banner and footer are still in Chinese in English mode.
- In the draft screen, Qian Ji's title and home-ground descriptions are still in Chinese.
- In the Armory, four case names, the skin codex tab, the type filter, the inventory count line, the skip controls, skin names in the preview and the "how to get" text are still in Chinese. The open button reads "On".
- Half of the open world info panel is still in Chinese.
- The home screen tagline says 12 heroes; there are 16.
- At 1280×720 the Armory tab in the top bar is covered by the Ink counter.
