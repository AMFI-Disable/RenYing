# 刃影平衡方案（Trainer，2026-10-27）

全部结论来自 `tools/trainer.mjs` 的电脑对电脑模拟：天道、劲敌两档各打一遍，13 个角色两两对打，每个对位 20 场（左右各半），每轮 6240 场，最后用一组没参与调整的新随机种子复核。基线是 main `e3bb90a` 加上本次的 AI 修复。

**原则：不改变英雄形象。** 不改招式、不改定位、不改手感：

- 数值只动 `BAL` 里每个角色的整体倍率，伤害（普攻、技能、大招）和气血一起乘同一个数，所以"打多疼、多耐打"会变，但角色之间谁打得疼、谁更肉的相对关系不变。
- 技能只改冷却，再加一处"墨团瞄准"，招式效果本身不变。

## 0. 先修 AI（已做完，在这次补丁里）

很多"不平衡"其实是 AI 不会应对某一招，不是角色本身太强：

| 问题 | 影响 | 修法 |
| :-- | :-- | :-- |
| 对手不会跳躲山崩 | 修之前铁山天道胜率 89% | 算好铁山落地时间起跳，来不及就闪（已进 main） |
| 满蓄力冲斩挡不住，但闪避在冷却时 AI 会站着"格挡" | 所有角色满蓄力冲斩打中的伤害里，四成以上打在"格挡中"的人身上 | 跑不出范围、闪避又没好的时候，迎上去在蓄满前打断 |
| 凌雀的大招在 AI 表里没有条目，换影也没有出手条件 | 凌雀的招牌连段（飞梭挂印记 → 换影引爆）AI 几乎不打 | 补上大招条目；换影只在对手带【雀芒】、闪避在冷却或正在挨打时放；飞梭打中后接换影引爆 |

后两处修完，打法更合理，但对整体胜率影响不大（各角色变动在几个百分点内）。修完以后各角色胜率（当前数值）：墨羽 83%、青锋 71%、月华 71%、流云 69%、玉箫 53%、绯影 48%、醉翁 44%、凌霜 41%、燕翎 38%、铁山 38%、雷鸣 37%、勾陈 34%、凌雀 24%。

## 2. 技能和大招修改建议（方案 B：先改技能，再补小一点的数值）

诊断工具 `tools/trainer-why.mjs` 统计了每个角色的伤害从哪来、挨打时自己在干什么。强势角色几乎都靠一招远程或一招定身吃掉大半伤害，弱势角色缺一个稳定的起手。

### 2.1 已经测过的 7 项（只改冷却和瞄准）

试验文件在 `docs/trainer/experiments/skill-tweaks.js`，不改游戏，只在模拟里套上去测。

| 角色 | 改动 | 原因（诊断数据） |
| :-- | :-- | :-- |
| 墨羽 | 普攻甩出的墨团不再自动飞向对手，固定落在身前约 220 像素 | 墨团占墨羽 26% 的伤害，自带 2.5 秒迟缓，而且每一下普攻都会自动瞄准。改了以后远处要自己找角度，近身照样能用 |
| 流云 | 风刃冷却 3.0 → 4.0 秒 | 风刃占流云 36% 的伤害 |
| 月华 | 月轮冷却 3.5 → 4.5 秒 | 月轮占 29%，对手被打中时多半在走路或蓄力 |
| 青锋 | 疾风斩冷却 5 → 6 秒 | 疾风斩占 30%，带 0.65 秒定身还重置冲刺 |
| 凌雀 | 穿叶飞梭冷却 6.5 → 5 秒 | 更容易挂上【雀芒】，让"飞梭 → 换影引爆"的招牌连段能打出来 |
| 勾陈 | 飞锤冷却 5 → 4 秒 | 勾陈缺稳定起手，飞锤拉近后还有 25% 增伤 |
| 勾陈 | 旋锤冷却 6 → 5 秒 | 旋锤占 20%，是勾陈最稳定的伤害 |

只改这 7 项（数值不动）：胜率 24%~83% 变成 30%~79%。流云 69 → 61、月华 71 → 66、墨羽 83 → 79、凌雀 24 → 30、勾陈 34 → 38。

### 2.2 还没测、值得试的技能/大招改动（都不改定位）

| 角色 | 建议 | 想解决的问题 |
| :-- | :-- | :-- |
| 墨羽 | 【墨迹遮目】迟缓 2.5 → 1.5 秒 | 墨团打中后对手跑不掉，接着被墨阵和蓄力打 |
| 青锋 | 疾风斩定身 0.65 → 0.45 秒（冷却可以改回 5） | 定身太长，打中就能稳接剑气和大招 |
| 月华 | 月镜反斩的超长硬直 1.05 → 0.8 秒 | 月镜一次 95 伤害，占月华 25% 的伤害 |
| 凌雀 | 【雀芒】持续 3.5 → 5 秒 | 印记常常在换影冷却好之前就消失了 |
| 勾陈 | 天网（大招）命中后重置飞锤冷却 | 让"大招 → 飞锤 → 连段"成为勾陈的招牌打法 |
| 雷鸣 | 雷闪起手更早进入霸体 | 雷鸣冲不进远程角色的身前，天道胜率只有 33% |
| 燕翎 | 俯冲在空中出手时，回升高度 +20% | 燕翎缺逃跑手段，天道胜率 40% |
| 铁山 | 山崩"怒意回涌"的连放从回满改成回 70% | 修 AI 前铁山靠连放山崩称霸；修好以后天道 25%、劲敌 51%，两档差太多，这条要和 AI 一起再看 |

每一条都可以照 `skill-tweaks.js` 的写法加进试验文件，用 Trainer 跑几千场看效果，再决定要不要进游戏。

### 2.3 试过但没用的通用规则（不建议做）

| 规则 | 结果 |
| :-- | :-- |
| 飞行道具伤害随飞行距离衰减（最低 50%） | 胜率范围几乎不变（25%~86%） |
| 每人场上最多 2 个会伤人的暗器 | 更糟（25%~87%），燕翎、绯影这类本来就弱的远程角色更弱 |
| 格挡住暗器回 6 点气 | 略有改善（23%~81%），但不够 |

结论：问题集中在几个角色的几招上，改通用规则会误伤别人，按角色逐招改更准。

## 3. 两档难度差得远的角色（要改 AI，不是改数值）

不论用方案 A 还是 B，下面几个角色在天道和劲敌两档的胜率都差 20 个百分点以上：

- 流云：天道 66% / 劲敌 33%
- 月华：天道 58% / 劲敌 41%
- 凌霜：天道 60% / 劲敌 37%
- 绯影：天道 37% / 劲敌 68%
- 铁山：天道 42% / 劲敌 60%

数值对两档是一起乘的，只能把平均值拉到 50%，拉不平两档之间的差。这要靠给每档难度单独训练打法基因（`tools/ai-train.mjs --lvkey hard`），或者像修山崩那样找出这些角色在某一档的 AI 漏洞。这是下一步建议做的事。

## 4. 推荐顺序

1. 合并这次的 AI 修复（满蓄力冲斩、凌雀出手）。
2. 采用方案 B：先改 2.1 的 7 项技能，再写入方案 B 的倍率。改动更小，更不容易被玩家觉得"角色变了"。
3. 挑 2.2 里的几条用 Trainer 试，效果好的再进游戏。
4. 做第 3 节的分难度 AI 训练。
5. 上线后看真人对战的胜率：AI 对打只是参考，真人的强弱可能不同。
