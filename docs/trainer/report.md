## 3. 平衡迭代过程

每轮：胜率每高出 50% 一个百分点，这个角色的伤害和气血就一起乘 (1 − 0.006)（第 r 轮再乘 0.75^(r−1)，越往后改得越细，免得来回摆），单轮最多 ±10%，总倍率限制在 0.6~1.4。伤害和气血一起动，招式手感、连段和出招速度都不变，只改“打多疼、多耐打”。

## 4. 怎么用这份建议

只在本地试，不影响游戏：

```bash
AI_BAL=docs/trainer/proposal.json node tools/ai-arena.mjs --a god --b god --n 10
AI_BAL=docs/trainer/proposal.json node tools/ai-arena.mjs --a hard --b hard --n 10
```

确定要用，就把 `docs/trainer/proposal.json` 里每个角色的 normal / skill / ult / hp 抄进 `src/game/02-heroes.js` 的 `BAL`，再运行 `python3 tools/build.py` 重新生成页面。

注意：这是电脑对电脑的结果，AI 打法和真人不一样（比如 AI 招架反应很快），真人对战的强弱可能不同；数值建议适合当参考起点，最好再结合玩家反馈。
