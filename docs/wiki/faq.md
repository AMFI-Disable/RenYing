# FAQ / 常见问题

## Joining A Friend's Room Times Out / 加入好友房间超时

Some networks (school Wi-Fi, office networks, some mobile carriers) block direct peer-to-peer links. The online edition then tries a relay through the game's server automatically. If it still fails:

1. Make sure both players are on the **same game version** (reload the page; the version is shown at the bottom of the account page).
2. Try another network, for example a phone hotspot.
3. Make sure you are not using the offline file; it has no online play.

有些网络（校园网、公司网、部分手机网络）会拦点对点连接，在线版会自动改走服务器中转。还是不行的话：两边刷新页面保证版本一样；换个网络（比如手机热点）；确认不是在用离线文件。

## My Progress Is Gone / 进度不见了

- **Guest or local account:** progress lives in that browser only. Clearing site data, private windows or another browser start from zero. Use the export button on the account page to keep a backup file.
- **Cloud account:** sign in again. Progress made while offline is kept on the device and sent when it can be. If the page says 登录过期, signing in again sends it.

游客和本机账号的进度只在这个浏览器里，清除网站数据、无痕窗口、换浏览器都会从零开始，记得在账号页导出备份。云端账号重新登录即可，离线时的进度会在联网后补发。

## The Game Asks Me To Turn My Phone / 让我把手机横过来

The game needs landscape. Turn the device sideways; touch controls appear automatically.

## Can I Play With Only A Keyboard / 能只用键盘玩吗

Yes. Every screen works with arrow keys or WASD, `Enter` and `Esc`, and `X` attacks. Turn on 纯键盘模式 in Settings so the mouse does not attack. See [Getting Started](getting-started.md).

可以。所有界面都能用方向键或 WASD、`Enter`、`Esc` 操作，`X` 是攻击。设置里打开纯键盘模式。

## Do Skins Make A Hero Stronger / 皮肤会变强吗

No. Armory items are cosmetic only. See [Armory And Marketplace](armory-and-marketplace.md).

不会，武库里的东西只改外观。

## Does It Cost Money / 要花钱吗

No. The game is free and open source, and there is nothing to buy with real money.

不要钱，游戏免费开源，没有任何真钱购买。

## I Found A Bug / 发现了 Bug

Open an [issue](https://github.com/AMFI-Disable/RenYing/issues/new/choose) with the steps, your browser and the game version. For anything that could let someone touch another player's account or items, follow [security.md](../../security.md) instead.

在 [Issues](https://github.com/AMFI-Disable/RenYing/issues/new/choose) 写清楚步骤、浏览器和游戏版本。涉及别人账号或物品安全的问题请按 security.md 私下报告。
