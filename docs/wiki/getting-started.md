# 🎮 Getting Started / 新手指南

## How To Play / 如何游玩

### 1. Online GitHub Pages (联网即玩)

Open [https://amfi-disable.github.io/RenYing/](https://amfi-disable.github.io/RenYing/) in any modern web browser (Chrome, Safari, Edge, Firefox). No installation, sign-up, or local web server is required.

### 2. Offline Standalone Edition (单文件离线珍藏版)

Open `renying-offline.html` directly from the repository in any browser. All 9 procedural and recorded audio tracks, textures, and the 3D Qingfengxing mini-game are embedded inside this single file.

---

## Language Preference / 语言设置

RenYing supports both **English** and **简体中文 (Simplified Chinese)**:

- On your first visit, a language choice dialog will appear.
- You can toggle the language anytime using the **语言 / Language** button (`#tnLangBtn`) in the top navigation bar or via the **Settings (设置)** panel.
- Your preference is saved across sessions.

---

## Controls / 操作方式

### Keyboard & Mouse (电脑键盘与鼠标)

- **Move (左右移动)**: `A` / `D`
- **Jump / Double Jump (跳跃 / 二段跳)**: `W` or `Space`
- **Block (防御)**: Hold `S`
- **Normal Attack (五连段普攻)**: Left Click
- **Heavy Slash (蓄力重斩)**: Hold Left Click, then release
- **Ranged Strike (暗器 / 剑气)**: Hold Left Click + Right Click (or `R`)
- **Aerial Flash / Dash (腾空闪 / 疾退)**: Right Click (or `Left Shift`)
- **Skill (绝技 / 招式)**: `Q`
- **Ultimate (大招)**: `E` (requires 100% Rage / 气满)
- **Pause / Mute (暂停 / 静音)**: `P` / `M`

### Mobile & Touch Controls (移动设备与触控屏)

When opened on a mobile device or tablet, RenYing automatically activates a virtual analog joystick on the left and responsive action buttons on the right.
