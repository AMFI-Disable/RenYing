# Getting Started / 新手指南

## Pick An Edition / 选一个版本

| Edition | How to open it | Has |
| :--- | :--- | :--- |
| **Online / 在线版** | <https://amfi-disable.github.io/RenYing/> in Chrome, Edge, Safari or Firefox | Everything: online play, accounts, armory market, open world |
| **Offline / 离线版** | Download `renying-offline.html` from the repository and double-click it | Single player, local multiplayer, music and the 青锋行 mini-game. No online modes, no cloud account |

在线版打开链接就能玩，所有模式都有；离线版是一个文件，双击打开，不用网络，但没有联机和云端账号。

## Language / 语言

The first visit asks for a language. Switch any time with the **语言 / Language** button in the top bar or in **设置 / Settings**. The choice is remembered.

第一次打开会让你选语言，之后随时可以在顶栏的 **语言 / Language** 或 **设置** 里切换，会记住你的选择。

| Action / 动作 | Mouse / 鼠标 | Keyboard / 键盘 |
| :--- | :--- | :--- |
| Move / 移动 | | `A` / `D` |
| Jump, double jump / 跳、二段跳 | | `W` or `Space` |
| Block (hold) / 防御（按住） | | `S` |
| Drop through a platform / 从平台跳下 | | `S` + jump |

| Charged slash / 蓄力斩 | Hold left click, release | Hold `X`, release |
| Skill 1 / 技能一 | | `Q` |
| Skill 2 / 技能二 | Hold left click + right click | `R` |
| Ultimate / 大招 | | `E` (full meter / 气满) |
| Escape / 腾空闪 | Right click | `Left Shift` |
| Pause / 暂停 | | `P` or `Esc` |
| Mute / 静音 | | `M` |

### Keyboard Only / 纯键盘

Every menu, dialog, the draft screen, pause, settings, results, story choices and tower scrolls work without a mouse. Arrow keys or WASD move a gold frame, `Enter` or `Space` presses, `Esc` goes back, `Tab` walks in order. Turn on keyboard-only mode in Settings if you do not want the mouse to attack.

所有菜单都能只用键盘：方向键或 WASD 移动金色选框，`Enter`/`空格` 确认，`Esc` 返回，`Tab` 按顺序走。设置里可以打开纯键盘模式，鼠标就不会出招。

### Phone And Tablet / 手机和平板

Turn the device sideways. A virtual stick appears on the left and action buttons on the right.

把设备横过来，左边是虚拟摇杆，右边是动作按钮。

## Your First Match / 第一局

1. Press **开始演武 / Play** on the home screen. The hero strip under it changes your hero.
2. Pick an AI level. **入门 / Easy** is a good start.
3. The draft screen (点将台) opens: pick your hero and confirm.
4. First to win **2 rounds** takes the match (at most 5 rounds).
5. The tutorial (新手教学) and the training dummy (木人桩) are the best places to learn combos.

中文步骤：

1. 主页点 **开始演武**，下面那排头像可以换侠客。
2. 选电脑难度，新手先选 **入门**。
3. 进入点将台，选好侠客确认。
4. 先赢 **2 回合** 的一方获胜（最多 5 回合）。
5. 想练连招就去新手教学和木人桩。

## Play With A Friend / 和朋友联机

1. Both open the online edition.
2. One player goes to **联机 / Online** → friend room (好友约战) and shares the 4-character room code.
3. The other types the code and joins.

If joining times out, see the [FAQ](faq.md). / 连不上请看 [常见问题](faq.md)。
