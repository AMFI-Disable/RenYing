# Welcome To The RenYing Wiki / 刃影 Wiki

[简体中文](home.zh-cn.md)

**[刃影 RenYing](https://bigbraindevbros.github.io/RenYing/)** is an ink-wash martial-arts fighting game that runs in a browser tab. Choose a hero for duels, 2v2 and 3v3 relay matches, story chronicles, co-op raids, a shared open world and peer-to-peer online play.


**[Play Now / 立即游玩](https://bigbraindevbros.github.io/RenYing/)** · **[Repository / 仓库](https://github.com/BigBrainDevBros/RenYing)** · **[Changelog / 更新日志](https://github.com/BigBrainDevBros/RenYing/blob/main/docs/history/changelog.md)** · **[Version History / 版本迭代史](version-history.md)**
